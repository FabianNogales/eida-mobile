# EIDA Control

Base Android Expo SDK 58 + React Native + TypeScript. Verificador QR v3 RS256 y diagnóstico con 29 vectores PHP; sin conexión a producción.

**Modo exclusivamente código:** el asistente revisa y escribe archivos; el usuario instala, ejecuta pruebas y compila. Consulta [AGENTS.md](AGENTS.md).

Estado: 44 pruebas de escritorio escritas, NO ejecutadas tras los últimos cambios. Los 40 éxitos anteriores son históricos. No hay APK generado ni verificación demostrada en Android.

Requiere Node compatible con engines (por ejemplo 22.23.1), SDK/JDK y una build nativa propia. Expo Go no contiene QuickCrypto. Los scripts mantenidos no crean unidades virtuales ni enlaces.
